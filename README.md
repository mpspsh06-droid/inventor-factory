# โรงงานนักประดิษฐ์ (Inventor Factory)

เกมวิทยาศาสตร์ ป.4 เรื่องสมบัติทางกายภาพของวัสดุ

## วิธีเปิดเล่น
1. แตกไฟล์ ZIP
2. เปิด `index.html` ใน Google Chrome เพื่อเล่นด้วยเมาส์ได้ทันที
3. หากต้องการเปิดกล้อง ให้เผยแพร่ผ่าน HTTPS เช่น GitHub Pages หรือเปิดผ่าน localhost แล้วกดปุ่ม **เปิดกล้อง**
4. อนุญาตให้เว็บไซต์เข้าถึงกล้องเมื่อเบราว์เซอร์ถาม
5. ยกมือให้อยู่ในกรอบกล้อง ใช้นิ้วชี้ค้างบนตัวเลือกประมาณ 1 วินาที

## เผยแพร่บน GitHub Pages
- สร้าง repository ใหม่
- อัปโหลด `index.html`, `style.css`, `script.js`
- ไปที่ Settings > Pages
- เลือก Deploy from a branch และเลือก branch `main` / root
- เปิด URL ที่ GitHub Pages สร้างให้

## หมายเหตุ
- กล้องใช้ `getUserMedia` จึงต้องเปิดผ่าน HTTPS หรือ localhost
- ระบบ AI ใช้ MediaPipe Hands ผ่าน CDN ต้องเชื่อมต่ออินเทอร์เน็ตในครั้งแรกและขณะเล่น
- หากไม่อนุญาตกล้อง สามารถเล่นด้วยเมาส์ได้ตามปกติ
- เสียงประกอบสร้างด้วย Web Audio API ไม่ต้องดาวน์โหลดไฟล์เสียงแยก
- ตัวเกมไม่บันทึกหรือส่งภาพจากกล้องไปยังเซิร์ฟเวอร์ของเกม การประมวลผล landmark ทำในเบราว์เซอร์
